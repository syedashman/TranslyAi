# TranslyAi

A multilingual speech-to-text and translation application built with a React + Vite frontend and a Python + FastAPI backend.

## Project structure

- `frontend/` – React UI with Vite, Tailwind CSS, and shadcn-inspired components
- `backend/` – FastAPI REST API and AI processing services
- `.env.example` – Shared environment variable template

## Getting started

1. Copy the environment templates.
2. Install frontend dependencies with `npm install` inside `frontend/`.
3. Install backend dependencies with `pip install -r backend/requirements.txt`.
4. Run the frontend and backend in separate terminals.

## Features

- Text and audio input
- Automatic language detection
- Translation to English
- Summary generation using Anthropic Claude
- Responsive modern UI
